# 🐛 Worm Master — 지렁이 게임

React와 TypeScript로 제작한 웹 기반 지렁이(Snake) 게임입니다. 먹이를 먹어 지렁이를 성장시키고 점수를 획득하는 기본 규칙에 다양한 게임 모드, 아이템, AI 대전, 스킨 및 업적 시스템을 추가했습니다.

## 🎮 주요 기능

- **4가지 게임 모드**
  - **클래식**: 사과를 먹으며 지렁이를 성장시키는 기본 모드
  - **아케이드**: 특수 아이템과 콤보를 활용하는 모드
  - **미로**: 배치된 장애물을 피하며 플레이하는 모드
  - **AI 대전**: AI 지렁이와 같은 경기장에서 경쟁하는 모드
- **3단계 난이도**: 쉬움 / 보통 / 어려움
- **먹이 및 파워업**: 일반 사과, 황금 사과, 자석, 슬로우, 유령 아이템
- **지렁이 스킨**: 클래식, 사이버, 황금 용, 젤리, 갤럭시 등 5종
- **업적 시스템**: 첫 사과 획득, 성장, 콤보, 고득점 등 총 8개 업적
- **기록 저장**: 게임 모드별 최고 점수와 업적, 선택한 스킨을 브라우저 `localStorage`에 저장
- **편의 기능**: 일시정지, 재시작, 부스트, 사운드 설정, 격자선 표시 및 터치 조작

## 🕹️ 조작 방법

| 조작 | 키 |
| --- | --- |
| 위·아래·왼쪽·오른쪽 이동 | 방향키 또는 `W` `A` `S` `D` |
| 부스트(가속) | `Shift` 누르기 |
| 일시정지 / 재개 | `Space` 또는 `P` |
| 게임 재시작 | `R` |
| 모바일 조작 | 화면의 방향 패드 및 부스트 버튼 |

## 🍎 아이템 안내

| 아이템 | 효과 |
| --- | --- |
| 🍎 일반 사과 | 10점 획득, 길이 1칸 증가 |
| ⭐ 황금 사과 | 50점 획득, 길이 2칸 증가 (일정 시간 후 소멸) |
| 🧲 자석 | 주변 사과를 끌어당김 |
| 🐢 슬로우 | 일정 시간 동안 이동 속도 감소 |
| 👻 유령 | 일정 시간 동안 충돌 및 벽 통과에 도움 |

> 아이템의 등장 여부와 적용 방식은 게임 모드에 따라 다릅니다.

## 🛠️ 사용 기술

- **언어**: TypeScript
- **프론트엔드**: React 19, Vite 8
- **스타일링**: Tailwind CSS 4
- **UI 및 애니메이션**: Lucide React, Motion, Canvas Confetti
- **게임 로직**: React 상태 관리, HTML Canvas 기반 렌더링 및 자체 AI 이동 로직
- **데이터 저장**: 브라우저 Local Storage

## 🚀 설치 및 실행

**필요 환경:** Node.js 및 npm이 설치된 컴퓨터

1. 저장소를 복제합니다.

   ```bash
   git clone https://github.com/ryu7297/game1.git
   cd game1
   ```

2. 필요한 패키지를 설치합니다.

   ```bash
   npm install
   ```

3. 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

4. 브라우저에서 **http://localhost:3000** 에 접속합니다.

### 기타 명령어

```bash
npm run build    # 배포용 파일 생성
npm run preview  # 빌드 결과 미리보기
npm run lint     # TypeScript 타입 검사
```

> 프로젝트에 `.env.example` 파일이 포함되어 있지만, 확인한 게임 화면과 로컬 AI 이동 로직에서는 Gemini API 호출이 사용되지 않습니다. 일반적인 로컬 게임 실행을 위해 API 키를 발급받을 필요는 없습니다.
